**Pour & Seap** добавляет в **Minecraft Java 1.20.1 (Fabric)** обычный стакан и винный бокал. Их можно поставить на стол, наполнить водой, молоком или вином из **[Let's Do] Vinery** и **NetherVinery**, выпить содержимое и забрать обратно.

## Возможности

- **Два 3D-предмета:** стакан и винный бокал. Оба можно установить как блок.
- Пустая посуда стакается до **16 штук**, наполненная — по одной.
- Поддержка **воды**, **молока** и вин из **Vinery / NetherVinery**.
- Необязательная интеграция с **Homeostatic**: питьё из стакана в руке или на столе восстанавливает жажду и насыщение водой по значениям оригинального напитка, без придуманных чисел.
- Красные вина отображаются бордовым цветом, остальные — светло-золотистым.
- При переливании, установке, разрушении и поднятии бокала сохраняются **оригинальный предмет вина, выдержка и данные NBT**.
- Эффекты при питье рассчитывает исходный мод вина.
- Вино можно перелить обратно в пустую бутылку `vinery:wine_bottle`, сохраняя исходное содержимое.
- Стандартная анимация питья Minecraft, звуки питья и переливания.
- Собственная вкладка достижений **Pour & Seap**, русский и английский языки.

## Использование

### Получение и крафт

Оба предмета находятся во вкладке Creative **Pour & Seap**:

```mcfunction
/give @s pour_and_seap:drinking_glass
/give @s pour_and_seap:wine_glass
```

Рецепты доступны на верстаке и в просмотрщике рецептов, если он установлен.

### Как налить жидкость в стакан в руках

Возьми **пустой стакан в правую руку**, а источник жидкости — **в левую**. Нажми ПКМ в воздухе:

| Источник | Содержимое | Что возвращается |
| --- | --- | --- |
| Ванильная бутылочка воды | Вода | Стеклянная бутылочка |
| Ведро молока | Молоко | Пустое ведро |
| Вино из Vinery / NetherVinery | Соответствующее вино | Пустая винная бутылка Vinery |

Удерживай ПКМ с наполненной посудой, чтобы выпить. Пустой стакан останется в инвентаре.

### Стакан, установленный как блок

Поставь пустой стакан на поверхность и **нажми по нему ПКМ с источником жидкости**. Чтобы забрать установленную посуду вместе с содержимым, **зажми Shift и нажми ПКМ пустой основной рукой**.

Наполненный стакан можно выпить прямо со стола, нажав по нему пустой рукой. Если сломать его в режиме выживания, содержимое сохранится в выпавшем предмете.

### Как перелить вино обратно в бутылку

Возьми **пустую винную бутылку Vinery** и нажми ПКМ по установленному бокалу с вином. Если бокал в руках, держи его в основной руке, пустую винную бутылку — во второй, затем нажми ПКМ в воздухе.

Вернётся исходная бутылка с её данными, включая возраст.

## Установка

1. Установи **Fabric Loader для Minecraft 1.20.1**, **Fabric API** и Java 17 или новее.
2. Добавь JAR мода в папку `mods/` **на сервере и на всех клиентах**, которые подключаются к нему.
3. Для вина установи подходящие версии **[Let's Do] Vinery** и/или **NetherVinery**. **Эти моды не обязательны**, если достаточно воды и молока.
4. Удали старые версии Pour & Seap и сделай резервную копию мира перед обновлением.

## Совместимость

| Мод / функция | Поддержка |
| --- | --- |
| Minecraft 1.20.1 и Fabric API | Обязательно |
| Вода и молоко Minecraft | Встроено |
| [Let's Do] Vinery | Необязательно |
| NetherVinery | Необязательно |
| Homeostatic | Необязательно; жажда восстанавливается по свойствам исходного напитка |
| Шейдеры и моды на 3D-тело | Зависит от конкретной сборки |

Эффекты вина и зависимость их продолжительности от выдержки остаются за оригинальным модом. Для обратного переливания необходима именно **пустая винная бутылка Vinery**.

## Сборка из исходников

Нужен JDK 17 и входящий в проект Gradle Wrapper:

```bash
./gradlew clean build
```

Итоговый JAR: `build/libs/pour_and_seap-0.3.2.jar`. GitHub Actions дополнительно проверяет ресурсы и автоматически собирает мод.

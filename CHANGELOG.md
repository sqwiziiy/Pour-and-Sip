# Changelog

## 0.3.2 — Homeostatic thirst compatibility

- Drinking from held or placed glasses now delegates thirst and water-saturation changes to Homeostatic when installed.
- Hydration is looked up from the original water bottle, milk bucket, or preserved Vinery/NetherVinery wine item.
- Uses Homeostatic's own datapack-configured hydration and effects; no hardcoded hydration values.
- Optional integration: existing behavior is unchanged when Homeostatic is not installed.

## 0.3.1 — First release

- Added Vinery and NetherVinery wine compatibility with original wine item/age preservation.
- Wine can be poured into held or placed glasses, then restored to its original bottle.
- Added a dedicated Pour & Seap advancements tab and fixed the placed-glass wine achievement.
- Added wine-pouring sounds alongside existing drinking sounds.
- Polished glass sizes, 3D models, water/milk rendering and inventory display.
- Empty glassware stacks to 16; filled glassware remains unstackable.
- Added English/Russian project documentation and GPL-3.0-only licensing.

## 0.3.0 — Wine integration

- Optional Vinery and NetherVinery support, red and golden wine appearance.
- Original wine ItemStack/NBT and age preserved while inside the glass.
- Initial advancements.

## 0.2.3 — Glassware polish

- Smaller glasses with improved contents visibility.
- Stacking limits and concise liquid tooltips.
